## Layout

| Token             | Value   | Role                        |
| ----------------- | ------- | --------------------------- |
| `--content-width` | `36rem` | Max width of content column |

**Desktop (≥600px):** Two columns — text left, photo right.
**Mobile (<600px):** Single column — photo first, then name, identity, links.
**Language toggle:** Top-right, aligned with content column edge.
